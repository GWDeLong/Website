Motivation

So far we have worked with data that is stagnant, doing analysis on all of the data instead of paying attention on how the data evolves over time. We now introduce an average which makes erratic data smooth.

Weighted Moving Averages

These averages are primarily used in forecasting and trend analysis where recent data is more relevant, we will weight the average so it leans more toward recent events.

Definition (Weighted Moving Average).

An average taken over \( n \) data values with increasing weights from 1 to \( n \), denoted \( \operatorname{WMA}( D ) \) where \( D \) is our data set.

Our general formula for the weighted moving average of length \( n \) is

\[ \operatorname{WMA}(D) = \frac{\text{Data Value 1 }(1) + \text{Data Value 2 }(2) + \dots + \text{Data Value n }(n)}{1 + 2 + \dots + n}. \]

Note.

For the first few entries -- depending on the size of our average -- will not have an average.

We now consider some examples.

Example 1.

Suppose we want to find a moving weighted average of length \( n = 3 \) for the following data set

Data Table
Index Data Value
1 5
2 3
3 6
4 5
5 9

Calculating our first weighted average, we take the first 3 values 5, 3, 6 weight them appropriately and divide by the sum of the weights, i.e., 

\[ \frac{5 (1) + 3 (2) + 6 (3)}{1 + 2 + 3} = \frac{29}{6} \approx 4.83 \]

We will record this in our table later. We now do so for the next three data values

\[ \frac{3 (1) + 6 (2) + 5 (3)}{1 + 2 + 3} = \frac{43}{6} = 5 \]

Lastly

\[ \frac{6 (1) + 5 (2) + 9 (3)}{1 + 2 + 3} = \frac{30}{6} = 7.17. \]

Hence in our table we have

Data Table
Index Data Value WMA
1 5 -
2 3 -
3 6 4.83
4 5 5
5 9 7.17
