Module 1: Set Theory

Introduction

In high school we have seen sets in a math context before! We typically see them as Domain, Range, and other collections of objects.

For the domain of a function \( f(x) \) defined on the interval \( [2, 3] \) we write 

\[ \text{Dom}(f(x)) = \{ x \in \mathbb{R} \colon 2 \leq x \leq 3 \},\]

read "The domain of \(f\) of \(x\) is the set of elements \(x\) in the real numbers \(\mathbb{R}\) such that \(x\) is greater than or equal to 2 and less than or equal to 3.

Definitions, Notations, and Conventions

We begin with the mathematical definition of a set.

Definition (Set).

A set is a container, or list, whose elements are mathematical "objects". 

Note that we are being intentionally vague on what is inside of a set to ensure that we are not limited in the future. 

Our next question is "How do we write our sets?"

Notation.

A set \( S \) is denoted by curly braces and elements are separated by commas. For instance, if \( S \) is the set of lowercase letters in the English alphabet, then we write 

\[ S = \{ a, b, c, \dots, z \}. \]

Mathematicians like order and structure, so it's natural to want to write out sets in specific ways, below are a few ways that we do that.

Conventions.

When we write out sets we note that they

  • are ordered if possible, e.g., alphabetically, numerically, etc.
  • exclude duplicate objects.

Examples

Definitions are not great if what we define doesn't exist, so here are some examples of what sets are .

Music is a set, we can write out some of its elements as

\[ \textbf{Music} = \{ \text{Green day, Rock, Blues}, \dots \}. \]

Movies as well

 \[ \textbf{Movies} = \{ \text{Iron Lung, The Odyssey, Flow}, \dots \}. \]

Rock Bands too

 \[ \textbf{Rock Bands} = \{ \text{ Green Day, Led Zeppelin}, \dots \}. \]

We now turn to ways to have sets interact with each other via set operations.

Set Operations.

Our first operation is a way to put sets together

Definition (Union).

The Union of sets \(A\) and \(B\), denoted \( A \cup B \), is the set containing all elements of \(A\) and \(B\).

As an example

\[ \textbf{Music} \cup \textbf{Movies} = \{ \text{Green day, Rock, Blues}, \dots, \text{ Iron Lung, The Odyssey, Flow}, \dots \}. \]

 

Next we want a way to figure out similarities

Definition (Intersection).

The intersection of sets \( A \) and \( B \), denoted \( A \cap B \), is the set containing only the elements of \( A \) and \( B \).

Another example

\[ \textbf{Music} \cap \textbf{Rock Banks} = \{ \text{Green Day, Led Zeppelin}, \dots \}. \]

Since Rock Bands are also elements of Music, we observe that we can write the intersection as

\[ \textbf{Music} \cap \textbf{Rock Banks} = \textbf{Rock Banks}.  \]

Thus far we have worked with words, but sets can contain anything, even other sets. We consider \( A = \{ 1, 3, 5 \} \) and \( B = \{ 1, 2, 3 \} \), taking the union and intersection we find

\begin{align*}
\text{Union:}  \quad &A \cup B = \{ 1, 2, 3, 5 \}, \\
\text{Intersection:} \quad &A \cap B = \{1, 3\}.
\end{align*}

A Special Set

As a final remark, we ask the question "How is \(A \cap B\) defined when \( A \) and \( B \) have nothing in common?" Our answer is found in the following defintion

Definition (The Empty Set).

The set with no elements is called the empty set and is denoted as \( \emptyset \). 

Note. The empty set is unique, i.e., there is only one empty set since all empty sets are the same.

Many intersections are the empty set, e.g., if we consider even numbers (0 is even) and odd numbers we find that they have nothing in common, hence

\[\{0, \pm 2, \pm 4, \dots \} \cap \{ \pm 1, \pm 3, \pm 5, \dots \} = \emptyset . \]
