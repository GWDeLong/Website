Module 2: Five Number Summary and Box Plots

Introduction

Now that we have some tools to understand data, we want to build some infrastructure that will make data presentation much neater.

Topics Covered in this Lecture

  • Quartiles

Motivation

Data presentation can be very difficult, we aim for models (graphs, plots, etc) which are easily readable and contain as much information as possible.

Quartiles

We begin with a definition

Definition (Quartile).

A quartile is a quarter, or 25%, of a data set.

Notation.

For the "break" points of the four quartiles, we denote them as follows.

\[Q_0 \;\overset{ \text{First Quartile}}{\rule{60pt}{2pt}}\; Q_1 \;\overset{ \text{Second Quartile}}{\rule{60pt}{2pt}}\; Q_2 \;\overset{ \text{Third Quartile}}{\rule{60pt}{2pt}}\; Q_3 \;\overset{ \text{Fourth Quartile}}{\rule{60pt}{2pt}}\;  Q_4 \]

Note.

The location of these break points depend on the distribution of data, below is an example of a non-even distribution.

\[Q_0 \;\rule{20pt}{2pt}\; Q_1 \;\rule{140pt}{2pt}\; Q_2 \;\rule{70pt}{2pt}\; Q_3 \;\rule{10pt}{2pt}\;  Q_4 \]

With a little intuition we realize that \( Q_0 \) and \( Q_4 \) are the minimum and maximum, respectively, of the data set and since \( Q_2 \) marks the center of the data it must be the median value. The other labels \( Q_1 \) and \( Q_3 \) are a little more elusive.

Observation (\( Q_1 \) and \( Q_3 \)).

We compute \( Q_1 \) and \( Q_3 \) as the medians of the first and last halves -- excluding the median -- of the data set.

As an example, take the following data set.

\[ D = \{ 2, 7, 23, 15, 17, 15, 19, 21, 8, 16, 15 \} \]

We first find the ordered data set \( \bar{D} \), this is read "\( D \) bar."

\[ \bar{D} = \{ 2, 7, 8, 15, 15, 15, 16, 17, 19, 21, 23 \} \]

Now we find the Median by eliminating outer terms

\[\cancel{2}, \cancel{7}, \cancel{8}, \cancel{15}, \cancel{15}, 15, \cancel{16}, \cancel{17}, \cancel{19}, \cancel{21}, \cancel{23}\]

Hence the median is 15. Now we look at the first half of the data, ignoring the median.

\[ 2, 7, 8, 15, 15 \]

The median of this smaller set is 8. Doing so again for the second half.

\[ 16, 17, 19, 21, 23 \]

We find a median of 19.

Putting our work together, we have found

\[ Q_1 = 8, \quad \text{Median} = 15, \quad Q_3 = 19\]

But what happens when we are given a data set of even length?

Consider another data set

\[ D = \{ 1, 2, 3, 4, 5, 6, 7, 8 \} \]

Finding the median we take the average of the two middle terms found as 

\[ \cancel{1}, \cancel{2}, \cancel{3}, 4, 5, \cancel{6}, \cancel{7}, \cancel{8} \]

Now averaging 4 and 5, we have

\[ \text{Median } = \frac{4 + 5}{2} = \frac{9}{2} = 4.5 \]

Therefore our median is 4.5. Looking at the first and last halves of the data, still not including our median,

\[1,2,3,4 \quad \text{and} \quad 5,6,7,8 \]

We find medians of 2.5 and 6.5, so 

\[ Q_1 = 2.5, \quad \text{Median} = 4.5, \quad Q_3 = 6.5 \]

Five Number Summary

Now that we have many different types of measurements of a data set, we want to be able to isolate the most important in a nice format.

Definition (Five Number Summary).

The five number summary is a list of the median, \( Q_1 \), \( Q_3 \), the minimum (denoted \( \text{Min} = \cdot \)), and the maximum (denoted \( \text{Max} = \cdot \)) of a given data set.
