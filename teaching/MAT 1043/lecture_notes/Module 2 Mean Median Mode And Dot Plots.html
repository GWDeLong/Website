Motivation

Data is one of the most important ways that mathematicians, statisticians, and other professionals engage with the world. Data is also extremely useful for the average person when interpreting collected information such as grades, income, etc.

Types of Data

Two major types of data exist and serve similar purposes, as you continue in your degree you will encounter both types, it is important for you to determine how valuable each is.

Definition (Qualitative Data).

Any data relating to the quality, meaning, or feelings towards something, a subjective measure.

An example of this type of data are responses to the question "Is [something] fun?" There is no correct answer to the question, however we can still measure the data and determine if something is enjoyable.

Definition (Quantitative Data).

Any data relating to quantities, numbers, and measurable events.

Attendance rates are an example of this type of data.

In this class we turn our focus to \( \star \) Quantitative Reasoning \( \star \), that is, reasoning with quantitative data.

Before we can work with our data, we need some way to structure our data, we do so with the following.

Definition (Data Set).

A set of data points which includes duplicates.

For instance, the set of favorite colors may look like the following 

\[ \text{Favorite Colors } = \left\{ \text{Blue, Blue, Red, Red, Red, Gray}, \dots \right\}. \] 

Now that we have data sets, what do we do with them?

Tools for Quantitative Reasoning

Below are a series of tools that we use to interpret data.

Definition (Mean or Average).

The "central" data value, computed as the sum of all data values divided by the total number of data points. 

As a formula we have

\[ \text{Mean } = \frac{\text{Sum of Values}}{\text{# of Values}}.  \]

Computing the mean of a sample data set \( \{ 1, 1, 2, 3 \} \), we add the values together, then divide by how many values there are, such as

\[ \text{Mean } = \frac{1 + 1 + 2 + 3}{4} = \frac{7}{4} = 1.75 \]

Our next tool is the median of a data set.

Definition (Median).

The middle value of the sorted data set.

The median is best described via example. Given a sorted data set \( \{ 1, 1, 2, 3, 4 \} \) we eliminate the outermost data values until we reach the center. Starting with the furthest out

\[ \{ \cancel{1}, 1, 2, 3, \cancel{4} \}  \]

then the next furthest out

\[ \{ \cancel{1}, \cancel{1}, \boxed{2}, \cancel{3}, \cancel{4} \}  \]

Therefore we found that

\[ \text{Median } = 2. \]

Note.

If we have a data set with an even amount of elements, we take the average of the two middle values. 

As an example, given the data set \( \{ 1, 1, 3, 25, 75, 80, 95, 100 \} \), we find the median value by first eliminating

\[ \{ \cancel{1}, \cancel{1}, \cancel{3}, 25, 75, \cancel{80}, \cancel{95}, \cancel{100} \}, \]

Now finding the average (or mean!) of 25 and 75, we have

\[ \text{Mean } = \frac{25 + 75}{2} = \frac{100}{2} = 50. \]

Thus

\[ \text{Median } = 50. \]

Another tool, which is not particularly useful to us, is the mode of a data set.

Definition (Mode).

The most frequent value in the data set.
